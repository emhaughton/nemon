# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-09

### Added

- Initial Docker development environment.
- PHP 8.5.
- Laravel 13.
- Vue 3 + TypeScript.
- Nginx.
- MySQL 8.4.
- Redis.
- Mailpit.
- phpMyAdmin.
- Dockerized frontend and backend.
- Non-root users inside PHP and Node containers.
- Project initialization script.
- Makefile with Docker, Laravel and Vue commands.
- Documentation for each infrastructure component.
- Environment configuration with `.env.docker` and `.env.local`.
